Flutter 原生全局跨组件状态管理方案 

# 一、方案1：

* 技术架构：`InheritedWidget`

* 特点：
  - 状态数据脱离 Widget Tree 独立存在，便于管理。
  - UI 的自动刷新仍然依赖 Widget Tree，无需手动刷新，响应式。

* 代码示例：

```dart
class User {
  final String name;

  const User(this.name);

  User copyWith({ String? name, }) {
    return User(name ?? this.name);
  }
}
```

```dart
class UserProvider extends InheritedWidget {
  final User user;

  const UserProvider({
    super.key,
    required this.user,
    required super.child,
  });

  static UserProvider of(BuildContext context) {
    // ⚠️：找到最近的 UserProvider；建立依赖关系；当数据变化时自动 rebuild；
    final provider =
        context.dependOnInheritedWidgetOfExactType<UserProvider>();

    assert(provider != null, "UserProvider not found");

    return provider!;
  }

  @override
  bool updateShouldNotify(UserProvider oldWidget) {
    return oldWidget.user != user;
  }
}
```

```dart
void main() {
  runApp(
    UserProvider(
      user: const User("Tom"),
      child: const MyApp(),
    ),
  );
}

// Widget Tree 下面获取数据：
final user = UserProvider.of(context).user;

// 修改数据：
UserProvider.of(context).user = UserProvider.of(context).user.copyWith(name: "Jerry");
// 或者
setState(() {
  UserProvider.of(context).user = const User("Jerry");
});
```

# 二、方案3：推荐！

* 技术架构：`InheritedNotifier<T> + ChangeNotifier`

```
定义 ChangeNotifier
          │
          │
将 ChangeNotifier 放在一个全局单例
          │
  InheritedNotifier
          │
    MaterialApp
          │
  整个 Widget Tree
```

* 优点：
  - 数据脱离 Widget Tree 独立存在，便于管理。
  - UI 的自动刷新仍然依赖 Widget Tree，无需手动刷新，响应式。

## 示例代码：

```dart
class UserModel extends ChangeNotifier {
  String _name = "Tom";
  int _age = 18;

  String get name => _name;
  int get age => _age;

  void login({
    required String name,
    required int age,
  }) {
    _name = name;
    _age = age;
    notifyListeners();
  }

  void changeName(String name) {
    _name = name;
    notifyListeners();
  }

  void logout() {
    _name = "";
    _age = 0;
    notifyListeners();
  }
}
```

```dart
class UserProvider extends InheritedNotifier<UserModel> {
  const UserProvider({
    super.key,
    required UserModel notifier,
    required Widget child,
  }) : super(
          notifier: notifier,
          child: child,
        );

  static UserModel of(BuildContext context) {
    // ⚠️：找到最近的 UserProvider；建立依赖关系；当数据变化时自动 rebuild；
    final provider =
        context.dependOnInheritedWidgetOfExactType<UserProvider>();

    assert(provider != null);

    return provider!.notifier!;
  }
}
```

```dart
// ⚠️，定义全局变量，在顶层文件定义
final userModel = UserModel();

void main() {
  runApp(
    UserProvider(
      notifier: userModel,
      child: const MyApp(),
    ),
  );
}


// Widget Tree 下面获取数据：
final user = UserProvider.of(context).user;

// 修改数据：
UserProvider.of(context).changeName("Jerry");

// 或者在顶层文件直接修改：
userModel.changeName("Jerry");
```
