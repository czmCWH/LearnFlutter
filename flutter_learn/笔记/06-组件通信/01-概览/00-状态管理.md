状态是指 当任何时候你需要重建你的用户界面时你所需要的数据。
如果状态是组件私有的，则应该由组件自己管理；如果状态要跨组件共享，则该状态应该由各个组件共同的父元素来管理。

## Flutter 内置的状态管理方式

1、setState 方法
  - 仅限于在单个 `StatefulWidget` 组件内进行状态管理。
  - 适用于**Widget 自身内部临时状态管理**。

2、InheritedWidget 抽象类
  - InheritedWidget 是用于在 Widget tree 中高效地向下传递数据的基类。即，**用于跨层级共享状态，但不支持跨组件共享状态**。
  - 把一个状态放在 Widget Tree 上层，下面的子节点可以通过 context 找到它，并在依赖变化时刷新。
  - InheritedWidget 是 `Provider package` 的底层实现。

3、InheritedModel 抽象类
  - InheritedModel 是 InheritedWidget 的子类。

4、ValueNotifier + ValueListenableBuilder
  - `ValueNotifier` 继承自 `ChangeNotifier`。
  - 

5、ChangeNotifier + ListenableBuilder
  - `ChangeNotifier` 继承自 `Listenable`，它是一个 mixin。
  - ChangeNotifier 适合承载一组状态，将状态从 widget 中抽离出来，便于管理。
  - **通过把 ChangeNotifier 定义为一个全局变量就可以实现全局跨组件共享状态**。


6、InheritedNotifier 抽象类
  - InheritedNotifier 是 InheritedWidget 的子类。
  - InheritedNotifier 是 `InheritedWidget + Listenable` 组合出来的。
  - InheritedNotifier 是 `GetX package` 的底层实现。

7、FutureBuilder / StreamBuilder

## 在Flutter中，管理状态有三种主要方式
1、每个 widget 管理自己的状态；
2、父 widget 管理 widget 的状态；
3、混合搭配管理的方法；
